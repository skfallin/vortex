# Vortex

Vortex is a Vite, React, and TypeScript landing page built from modular sections and reusable components.

Live site: https://vortex-omega-two.vercel.app

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
